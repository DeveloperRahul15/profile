# Rahul Choubey — Personal Portfolio

Premium vanilla portfolio — HTML5, CSS3, JavaScript (ES modules), GSAP, ScrollTrigger, and Lenis.

## Quick Start

**Do not double-click `index.html`** — browsers block ES modules over `file://`.

### Option 1 — Terminal

```bash
npm run dev
```

Open **http://127.0.0.1:5501**

### Option 2 — One-click (Linux)

```bash
chmod +x start.sh
./start.sh
```

This starts the server and opens your browser automatically.

See [vanilla/README.md](vanilla/README.md) for structure, customization, and deployment notes.
